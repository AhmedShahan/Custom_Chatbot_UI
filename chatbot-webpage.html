RAG Chatbot Demo

This is a demonstration page for the RAG (Retrieval-Augmented Generation) chatbot. Click the chat bubble in the bottom-right corner to interact with the chatbot.

About this Chatbot

This RAG chatbot can retrieve information from documents and provide intelligent responses. Click the chat bubble to enter the URL of your chatbot server and start interacting with it.

The chatbot allows you to:

  • Upload and process documents
  • Extract information from websites
  • Ask questions about the content
  • Get AI-powered responses

How to Use

1. Click the blue chat bubble in the bottom-right corner
2. Enter the URL of your chatbot (e.g., http://127.0.0.1:8501/)
3. The chatbot interface will open, allowing you to interact with it
4. Use the chat interface to ask questions about your documents
